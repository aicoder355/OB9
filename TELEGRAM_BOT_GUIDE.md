## Запуск бота

### 1. Настройка окружения

Скопируйте `.env.example` в `.env` и заполните необходимые данные:

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_MODE=polling
TELEGRAM_ADMIN_CHAT_IDS=ваш_chat_id
DRIVER_CODE_EXPIRY_HOURS=24
```

> **Как получить chat_id:**
> 1. Напишите боту [@userinfobot](https://t.me/userinfobot) в Telegram
> 2. Он отправит вам ваш chat_id

### 2. Применение миграций

```bash
python manage.py migrate
```

### 3. Запуск бота

```bash
python manage.py run_telegram_bot
```

Бот запустится в режиме long-polling и будет работать до тех пор, пока вы не остановите его (Ctrl+C).

## Для клиентов

### Регистрация

1. Найдите бота в Telegram по имени или ссылке
2. Отправьте команду `/start`
3. Используйте команду `/register`
4. Следуйте инструкциям:
   - Введите ваше имя
   - Введите номер телефона (формат: +998901234567)
   - Введите адрес доставки

После регистрации ваша заявка будет отправлена администратору на подтверждение.

### Просмотр каталога

**Команда:** `/catalog` или кнопка "📋 Каталог товаров"

Показывает список всех доступных товаров с ценами.

### Создание заказа

**Команда:** `/order` или кнопка "🛒 Сделать заказ"

1. Выберите товар из списка
2. Выберите количество
3. Подтвердите адрес доставки
4. Заказ создан! Вы получите уведомление с номером заказа

### Просмотр заказов

**Команда:** `/myorders` или кнопка "📦 Мои заказы"

Показывает список ваших активных заказов со статусами.

### Уведомления

Вы автоматически получите уведомления когда:
- ✅ Заказ принят
- 🚗 Назначен водитель
- 📍 Заказ в пути
- ✅ Заказ доставлен
- ❌ Заказ отменён

## Для водителей

### Авторизация

1. Получите код доступа у администратора
2. Отправьте команду `/driver_login`
3. Введите полученный код

Код действителен 24 часа.

### Просмотр доставок

**Команда:** `/my_deliveries` или кнопка "📋 Мои доставки"

Показывает список назначенных вам заказов с информацией:
- Номер заказа
- Имя и телефон клиента
- Адрес доставки
- Товар и количество
- Сумма заказа

**Сортировка:**
- 🔤 По адресу - удобно для планирования маршрута
- 🕐 По времени - сначала старые заказы

### Обновление статуса заказа

Используйте inline кнопки под каждым заказом:

- **🚗 В пути** - заказ взят в работу
- **✅ Доставлен** - заказ выполнен
- **❌ Отменён** - заказ отменён (с комментарием)
- **📝 Добавить комментарий** - добавить примечание

### Загрузка фото (опционально)

После доставки вы можете отправить фото подтверждения:
1. Обновите статус на "Доставлен"
2. Отправьте фото в чат с ботом

### Уведомления

Вы получите уведомление когда:
- 📦 Вам назначен новый заказ
- ℹ️ Изменены детали заказа

## Для администраторов

### Генерация кода доступа для водителя

```bash
python manage.py generate_driver_code <driver_id>
```

Пример:
```bash
python manage.py generate_driver_code 1
```

Вывод:
```
✅ Access code generated for driver: Иван Иванов
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CODE: A7B9C2D4
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Valid for 24 hours

Driver should use /driver_login in Telegram bot
and enter this code.
```

Передайте этот код водителю.

### Подтверждение регистрации клиента

1. Вы получите уведомление в Telegram о новой регистрации
2. Откройте Django Admin: http://localhost:8000/admin/
3. Перейдите в раздел "Клиенты" (Clients)
4. Найдите клиента по имени или телефону
5. Измените поле "Registration status" на "Подтверждён" (approved)
6. Сохраните

Клиент автоматически получит уведомление и сможет делать заказы.

### Назначение водителя на заказ

1. Откройте Django Admin
2. Перейдите в раздел "Заказы" (Orders)
3. Выберите заказ
4. В поле "Driver" выберите водителя
5. Сохраните

Водитель автоматически получит уведомление о новом заказе.

### Уведомления администратора

Вы получите уведомления о:
- 🆕 Новой регистрации клиента
- 🛒 Новом заказе

Для получения уведомлений добавьте ваш chat_id в `.env`:
```env
TELEGRAM_ADMIN_CHAT_IDS=123456789,987654321
```

Можно указать несколько chat_id через запятую.

### Команды для клиентов

- `/myorders` - Мои заказы

### Команды для водителей
- `/driver_login` - Авторизация водителя
- `/my_deliveries` - Список доставок

## Устранение неполадок

### Бот не отвечает

1. Проверьте, запущен ли бот: `python manage.py run_telegram_bot`
2. Проверьте токен в `.env`
3. Проверьте логи в консоли

### Не приходят уведомления

1. Убедитесь, что у клиента/водителя привязан telegram_chat_id
2. Проверьте настройки TELEGRAM_ADMIN_CHAT_IDS в `.env`
3. Проверьте, что бот не заблокирован пользователем

### Код доступа водителя не работает

1. Проверьте, не истёк ли срок действия кода (24 часа)
2. Сгенерируйте новый код: `python manage.py generate_driver_code <id>`
3. Убедитесь, что водитель вводит код правильно (заглавными буквами)

## Дополнительная информация

### Структура проекта

```
crm/
├── bot_keyboards.py      # Клавиатуры для бота
├── bot_handlers.py       # Обработчики команд
├── telegram_bot.py       # Основной модуль бота
├── signals.py            # Сигналы для уведомлений
└── management/
    └── commands/
        ├── run_telegram_bot.py        # Запуск бота
        └── generate_driver_code.py    # Генерация кодов
```

### Логирование

Все действия бота логируются в консоль. Для сохранения логов в файл настройте Django logging в `settings.py`.

### Безопасность

- ⚠️ Никогда не коммитьте файл `.env` в Git
- ⚠️ Храните токен бота в секрете
- ⚠️ Коды доступа водителей действуют только 24 часа
- ⚠️ Используйте HTTPS для webhook режима (для продакшена)
